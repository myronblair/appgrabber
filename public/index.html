How it works

  1. Tick the apps you want, or start from a preset (New Workstation, New Server, MSP Tech Toolkit…).
  2. Press Get Installer. You download a small .exe built just for your selection.
  3. Run it. Windows asks for administrator rights once, then every app installs silently. No toolbars, no prompts.

The installer uses the Windows Package Manager (winget) on Windows 10 1809+, Windows 11 and Server 2025. On older systems it falls back to each vendor's direct download where available. A log is saved to %TEMP%\AppGrabber.log.
